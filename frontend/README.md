## 🌟 ওভারভিউ ও ফ্রন্টএন্ড বৈশিষ্ট্যসমূহ

- **Strict NO-Modals Policy**: কোনো ব্লকিং ব্রাউজার পপআপ বা উইন্ডো ডায়ালগ নেই। প্রতিটি কাজ ডেডিকেটেড পেজ এবং সুরক্ষিত রাউটে সম্পন্ন হয়।
- **Zero-Crash ErrorBoundary**: যেকোনো আনহ্যান্ডেলড জাভাস্ক্রিপ্ট ত্রুটি ধরলে সম্পূর্ণ পেজ ব্ল্যাংক হওয়া রোধ করে একটি মসৃণ রিকভারি স্ক্রিন দেখায় এবং ত্রুটিটি সরাসরি ব্যাকএন্ডের `POST /api/system/report-error` এ পাঠিয়ে দেয়।
- **Section Maintenance Screen & Developer Preview**: কোনো মডিউল রক্ষণাবেক্ষণে থাকলে সাধারণ ব্যবহারকারীদের জন্য নোটিশ দেখায়, আর সুপার অ্যাডমিনদের জন্য থাকে ফ্লোটিং "Developer Preview Active" ব্যানার।
- **ক্যাশিয়ারদের থেকে ক্রয় মূল্য গোপন (Wholesale Cost Protection)**: ক্যাশিয়ার লগইন অবস্থায় `ProductList.jsx` এবং `ProductDetails.jsx`-এ পাইকারি ক্রয় মূল্য (Cost Price) এবং ইউনিট লাভ সম্পূর্ণ হাইড থাকে।
- **Measurement Value & Stock Separation**: প্রতিটি পণ্যের নামের পাশে নেট ওজন/পরিমাপ (যেমন: ১০০ গ্রাম মাখন) এবং বর্তমান ইনভেন্টরি স্টক (যেমন: ৫০ পিস) সুন্দর ব্যাজে আলাদাভাবে প্রদর্শিত হয়।
- **রিয়েল-টাইম লাইভ ঘড়ি**: টপ নেভবারে রানিং সেকেন্ডস সহ ঢাকা টাইমজোনের লাইভ ডিজিটাল ঘড়ি।
- **দ্বিভাষিক সমর্থন (Bilingual)**: এক ক্লিকে বাংলা ও ইংরেজি রূপান্তর (মুদ্রা: ৳, সংখ্যা রূপান্তর সহ)।
- **ডার্ক ও লাইট মোড**: আধুনিক রিটেইল ডিসপ্লের জন্য অপ্টিমাইজড কালার থিম।

## ⚙️ এনভায়রনমেন্ট কনফিগারেশন (`.env`)

`frontend/.env` ফাইলে নিচের সেটিংস নিশ্চিত করুন:

```env
# Backend API Base URL
VITE_API_URL=http://127.0.0.1:8000/api

# Backend Server Root URL (ইমেজ ও স্টোরেজ লিংকের জন্য)
VITE_BACKEND_URL=http://127.0.0.1:8000

# Application Name
VITE_APP_NAME="ISRAFIL BD SHOP"

# দ্রুত ডেমো লগইন বাটন হাইড/শো (true = hide, false = show)
VITE_HIDE_QUICK_LOGIN=false
```

## 🏗️ প্রধান আর্কিটেকচারাল কম্পোনেন্টসমূহ

1. **`ErrorBoundary.jsx` (`src/components/common/ErrorBoundary.jsx`)**:
   - পুরো অ্যাপ্লিকেশনের ক্র্যাশ সুরক্ষা প্রদান করে।
   - ত্রুটি হলে ইউজার ফ্রেন্ডলি রিলোড ও পূর্বের পেজে ফেরার বাটন দেখায় এবং স্বয়ংক্রিয়ভাবে ব্যাকএন্ড লগ তৈরি করে।

2. **`SectionMaintenanceScreen.jsx` & `SuperAdminMaintenanceBanner.jsx`**:
   - সেকশন রক্ষণাবেক্ষণ নিয়ন্ত্রণ ও অ্যাডমিন প্রিভিউ নিশ্চিত করে।

3. **কনটেক্সট প্রোভাইডারসমূহ (`src/context/`)**:
   - `AuthContext`: লগইন সেশন, রোল ও গ্র্যানুলার পারমিশন চেকিং (`hasPermission()`).
   - `LanguageContext`: বাংলা ও ইংরেজি অনুবাদ এবং মুদ্রা ফরম্যাটিং (`formatCurrency()`).
   - `ThemeContext`: ডার্ক/লাইট মোড স্টেট।
   - `ToastContext`: আধুনিক স্ট্যাকড নন-ব্লকিং নোটিফিকেশন সিস্টেম।
   - `SystemModuleContext`: সিস্টেম সেকশন লাইভ স্ট্যাটাস।

4. **সার্বজনীন ইমেজ রেজলভার (`src/utils/imageUrl.js` বা `ProductCardMedia.jsx`)**:
   - গুগল ড্রাইভ, এক্সটার্নাল সিডিএন এবং লোকাল স্টোরেজ পাথ অটো-ডিটেক্ট করে সঠিকভাবে প্রোডাক্ট ছবি রেন্ডার করে।

## 🖨️ পিওএস ও থার্মাল প্রিন্টিং সিস্টেম

- **প্রিন্ট ফরম্যাটসমূহ**:
  - `58mm`: ছোট পোর্টেবল ব্লুটুথ ও ইউএসবি থার্মাল প্রিন্টারের জন্য।
  - `80mm`: স্ট্যান্ডার্ড রিটেইল সুপারশপ কাউন্টার প্রিন্টারের জন্য।
  - `A4`: পূর্ণাঙ্গ চালান বা প্রাতিষ্ঠানিক রসিদের জন্য।
- **SVG ভেক্টর বারকোড**: থার্মাল প্রিন্টে স্পষ্ট বারকোড পেতে কাস্টম ভেক্টর SVG ইঞ্জিন ব্যবহার করা হয়েছে।
- **শর্টকাট কিবোর্ড কি**:
  - `Alt + K`: বারকোড ও প্রোডাক্ট সার্চ ফিল্ডে কার্সার ফোকাস।
  - `Enter`: সরাসরি চেকআউটে আইটেম যুক্ত করা।
  - দ্রুত টেন্ডার বাটন: `+৳৫০`, `+৳১০০`, `+৳৫০০`, `+৳১০০০`।

প্রোডাকশন অপ্টিমাইজড বান্ডেল তৈরি করতে:

লোকালি প্রোডাকশন বিল্ড প্রিভিউ করতে:
```bash
npm run preview
```
